- **Proxmox VE**: a VM without the balloon driver (or with ballooning off, like firewall appliances) no longer
  shows close to 100% memory. Proxmox can only see the memory such a VM holds on the host, so CorePulse now
  marks it "not reported by the guest" and, when the node is polled with SNMP, shows the guest's own figure.
- A VM linked to a node on its Edit page is no longer also matched to another node by IP, MAC or name, so one
  box monitored as two nodes (a firewall's management and data addresses) shows its VM on the chosen node only.
