**Muted messages, for every event**

- Mute is offered next to every event (Events page, a node's and a container's events, the Summary's recent
  events), not only next to a device's syslog messages: a flapping node, a container that restarts every
  night, a repeating warning from any part of CorePulse. A rule can be limited to one event type, and it
  mutes both the events and the alerts sent with them (an alert is muted when it contains the rule's text and
  is about the rule's device). Configuration changes (who changed what) are never muted.
