- Upgrades no longer stop with "chmod: changing permissions of '.corepulse/tls': Operation not permitted".
  Installs first upgraded from a version before 0.11.0 got that folder from Docker, owned by root; corepulsectl
  now makes an empty one again with the right owner, and only warns (with the command to fix it) when one
  with files in it belongs to someone else. Installs on 0.11.0 to 0.11.3 that hit this need one command before
  upgrading, because their own corepulsectl does the check: in CorePulse's folder,
  `sudo chown -R "$(id -un):$(id -gn)" .corepulse/tls` (see docs/UPGRADE.md, "When something goes wrong").
