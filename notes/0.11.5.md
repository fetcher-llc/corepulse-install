- Interface error alerts no longer flip between "has errors" and "OK again" when a rate hovers at the limit.
  Errors must now last a while before they alert (Settings → SNMP → "...for at least (minutes)", 10 by
  default), and an alerting interface only counts as OK again once its errors drop below half the limit.
- Wi-Fi radios and networks (an access point's SSID interfaces, wlan interfaces) have their own error limit,
  10 per second by default (Settings → SNMP → "Wi-Fi interface errors", 0 = no alerts): Wi-Fi always counts
  some errors from interference and distant devices, so the wired limit of 1 per second was too strict there.
- Aruba Instant: a member AP's Wi-Fi interfaces are named after their network and band again (for example
  "SHALOM-Home (5 GHz)"). Only the conductor lists the cluster's networks, so an AP that stopped being the
  conductor lost its names; it now uses the list another node of the same cluster reported. The virtual
  controller address shows the band too.
- Summary: the tooltip of a tile in the top row is no longer hidden behind the tile below it.
