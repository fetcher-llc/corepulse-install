- A node follows its device when the device gets a new IP address, so moving devices to another network no
  longer leaves a dead node and a "new" device to add again. Nodes remember their device's MAC address (filled in
  for nodes added from discovery and when discovery sees the device at the node's address; editable on the node's
  Edit page). When discovery sees that MAC at a new address, the node's address is updated with an event, once
  the node no longer answers at the old one, the device was seen at that one address only, no other node has it,
  and the node is set to an IP address rather than a DNS name. Settings → Discovery → "Update a node's address
  when its device moves" (on by default) switches this off.
- Discovery → Add as node: a device that is already a node at its old address updates that node instead of
  adding a second one.
- Nodes: devices that were added more than once (same MAC address) are listed at the top, with a Merge button
  that keeps the oldest node and its history at the newest copy's address and deletes the other copies.
