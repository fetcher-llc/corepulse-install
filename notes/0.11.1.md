- Speed tests can use LibreSpeed instead of Cloudflare (Settings → Internet monitoring): one of 22 public
  LibreSpeed servers, the nearest of them (measured once a week), or your own LibreSpeed server. Each test
  records which server it used (Internet page). Works with the servers' differing limits (a new connection
  after 3 requests, uploads made smaller when a server says they are too large), and says so plainly when a
  server refuses a test.
