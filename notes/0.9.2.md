From a review of a first install by someone else (thank you).

**Security**

- Release bundles are now signed (Sigstore, like the images). The installer and `corepulsectl` check the
  bundle's signature as well as its checksum, and say so: "Signature verified".
- Signature checks are now required by default: a failed check stops the install or upgrade before anything
  changes. `COREPULSE_VERIFY=warn` or `off` (in `.env`, or before the command) relaxes it, e.g. for servers
  without internet access; see the install guide, *Signatures*.
- The ready-made images (PostgreSQL, Caddy, the Docker socket proxy, cosign) are pinned by digest instead of
  floating tags such as `postgres:16-alpine`.

**Changes**

- Access control's RADIUS server is no longer installed by default: no container and no open UDP 1812/1813
  until `./corepulsectl access-control on`. Installs that already have access control switched on keep it.
- The installer checks that the site's names are in DNS, warns about the ones that are not, uses the IP
  address for links until they are, and ends with a clear summary: the addresses, the setup code and the
  result of the signature checks.
- The guides' examples show the current version.
