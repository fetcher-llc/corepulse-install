- **Proxmox VE**: CorePulse now reads Proxmox VE (Settings → Proxmox VE) the way it reads vCenter: nodes, VMs,
  containers and storages with their CPU, memory, disk and network use, on the Virtualization page, the node
  pages, the map and Top 10. It uses a read-only API token (the settings page shows the four commands that
  create one) and pins the server's certificate. Alerts when a Proxmox node goes offline or a storage runs low
  on space. VM IP addresses come from the QEMU guest agent; nodes are also matched to their VM by MAC address.
- vCenter and Proxmox can be used side by side. Switching either one off now takes its VMs, hosts and storage
  off the Virtualization page (their history is kept), so VMs that no longer exist stop counting for their
  nodes. On upgrade, the VMs of a vCenter connection that is already switched off are cleared away the same way.
