The first release for others to install: a beta, in daily use on its author's network. Expect rough edges,
and please report them.

**Monitoring**

- Ping and availability for every node, with parent/child dependencies, maintenance windows and a
  per-host maintenance mode during upgrades.
- SNMP v2c and v3 for switches, firewalls, access points, printers, NAS boxes, UPSes and Linux servers:
  CPU, memory, disks, interfaces and their traffic, temperatures, PoE, Wi-Fi radios and clients; choose
  per device what to monitor.
- Application monitors: web pages, TCP ports, DNS, NTP, processes, Windows services, Active Directory
  health, with ready-made starters.
- Windows servers through the read-only windows_exporter agent, installable remotely from CorePulse;
  Windows Update status, and optional patching (off by default).
- VMware vCenter (VMs, hosts, datastores), Docker containers, Palo Alto firewalls through their XML API.
- Internet monitoring with speed tests, and hop-by-hop network path monitoring.

**Seeing and understanding**

- Summary page, events, a network map (physical and logical) drawn from switch tables, vCenter and your
  networks, Top 10 lists and monthly availability reports.
- Syslog and SNMP traps with anomaly detection; NetFlow, IPFIX and sFlow traffic flows; IoT device
  inventory and behaviour; device configuration backups with differences.
- Analysis: optional questions to Claude about your logs, traffic and devices.
- A family status page, and a device setup guide for 36 makes of equipment.

**Running it**

- Alerts by email (any mail server or Gmail), ntfy push, Discord, Slack, Microsoft Teams, Home Assistant
  and webhooks; an alert pause button; availability reports by email.
- Local accounts and Active Directory, admin and read-only roles; network access control (RADIUS) for
  Wi-Fi and wired devices, off by default.
- Nightly backups, optionally encrypted and copied to an SMB share or NFS export; restore from the web
  interface or the command line; clearing collected data while keeping all settings.
- Install, upgrade (with automatic rollback), offline bundles and update notices with `corepulsectl`.
- Security: server-side sessions, a one-time setup code for new installs, limited database accounts,
  signed images, strict content security policy; see docs/SECURITY.md.
